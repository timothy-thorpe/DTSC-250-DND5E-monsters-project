This repository contains a project I worked on during my Spring 2025 semester for DTSC-250 "Stats using R." This was the final project for the course, demonstrating not only knowledge of R
and its various libraries, but also key concepts such as linear regression and correlation. The goal of the project was to be able to predict the combat rating of a monster in Dungeons and
Dragons. I was asked to present this at the Eastern University health and sciences' research symposium, and have included the presentation poster for that as well.
